「Invalid CSV header（無効なCSVヘッダー）」エラーの意味と直し方

この記事は非公式の解説です。Shopify社とは提携・推奨等の関係はありません。Shopify の公式サイトは www.shopify.com です。

内容は、2026年11月17日時点で確認した Shopify ヘルプセンターの公開ページの記述の範囲に限っています。エラー名は公式ヘルプ（英語版）の表記「Invalid CSV header: missing headers」を元にしており、「無効なCSVヘッダー」はこの記事での訳です。管理画面の日本語表示の文言とは異なる場合があります。

このエラーの意味

商品CSVの1行目（列ヘッダー）が、Shopify が期待する列名と一致していないことを示すエラーです。公式ヘルプでは次のように説明されています。

  • 商品CSVの1行目は、商品CSVの説明表で指定された列ヘッダーでなければなりません。各列はカンマで区切ります。
  • 列ヘッダー名は大文字・小文字を区別します。ヘッダーがサンプルファイルと正確に一致しないとエラーになる旨が、トラブルシューティングに記載されています。
  • 「Invalid CSV header: missing headers」の対処として、1行目の末尾の余分な空白を確認するよう案内されています。
  • また「Network error: Unexpected token < in JSON at position 0」というエラーも、列タイトルがテンプレートのヘッダーと正確に一致しない（大文字・小文字を含む）場合のものとして案内されています。

よくある原因と直し方

1. 列名のつづり・大文字小文字が違う

例：title（小文字）や Colour のように、公式の列名と完全一致しない列名。公式のサンプルCSVの1行目、または商品CSVの説明表の列名に合わせて直します（例 Title、URL handle、Price）。不要な列なら削除します。

2. 列名の前後に余分な空白がある

例：Title （末尾に空白）。特に1行目の末尾の空白は見落としやすい箇所です。空白を削除して、列名を完全一致させます。

3. 旧形式の列名を使っている

公式ヘルプのトラブルシューティングには、Handle、Body (HTML)、Variant Price、Image Src などの列名を使った1行目の例が載っています。一方、現行の商品CSVの説明表と公式サンプルでは URL handle、Description、Price、Product image URL などの列名が使われています。旧形式の列名が現行のインポートで受理されるかどうかは、公式ヘルプでは確認できていません。確実を期すなら、公式サンプルCSVの1行目の列名に合わせることを検討してください。

4. 公式資料どうしで表記が違う列

いくつかの列は、説明表と公式サンプルで表記が異なります（例：説明表の Barcodes とサンプルの Variant Barcodes、説明表の Option1 LinkedTo とサンプルの Option1 Linked To、Google Shopping / Google Product Category と Google Shopping / Google product category）。どちらが現行のインポートで受理されるかは、公式ヘルプでは確認できていません。

事前チェッカーでの確認

事前チェッカーは、1行目の各列名を公式の説明表・公式サンプルの列名と照合し、次のように表示します。

  • どの公式列名とも一致しない列名 → 「仕様不適合（C07）」。大文字・小文字だけが違う場合はその旨も表示します。
  • 列名の前後の空白 → 「仕様不適合（C08）」。
  • 旧形式の列名 → 「注意（C09）：現行インポートでの受理可否は公式未確認」。このとき値の検査は行わず「対象外・未検査」と表示します。
  • 公式資料どうしで表記が違う列 → 「注意（C07）：受理可否は公式未確認」。

チェッカーの結果はインポートの成功を保証するものではありません。ファイルはブラウザ内だけで処理し、送信しません。
