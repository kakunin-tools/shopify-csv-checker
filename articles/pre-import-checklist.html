Shopify商品CSVのインポート前にやる事前チェック手順

この記事は非公式の解説です。Shopify社とは提携・推奨等の関係はありません。Shopify の公式サイトは www.shopify.com です。

内容は、2026年11月17日時点で確認した Shopify ヘルプセンターの公開ページの記述の範囲に限っています。ここに挙げた確認をすべて行っても、インポートの成功が保証されるわけではありません。

この記事の対象：Shopify商品CSV・標準テンプレート・バリエーションなし・1商品1レコード・新規下書き登録。

手順1：ファイル全体を確認する

  • 文字コードは UTF-8。公式の必須条件です（文字化けの記事も参照）。
  • ファイルサイズは 15 MB 以下。超える場合は複数のファイルに分割するよう公式に案内されています。
  • 引用符の使い方。カンマを含む値（例：タグの一覧）は "tag1,tag2,tag3" のようにストレートな引用符で囲みます。曲がり引用符（“ ”）を囲みに使ったり、引用符が不足・余分だったりすると、エラー（Illegal quoting／Missing or stray quote）の原因になります。
  • 各行の列数がヘッダーと同じであること。

手順2：1行目（列ヘッダー）を確認する

  • 列名は公式の説明表・公式サンプルCSVと完全一致させる（大文字・小文字を区別）。
  • 列名の前後、特に1行目の末尾に余分な空白がないこと。
  • 詳しくは「Invalid CSV header（無効なCSVヘッダー）」の記事を参照してください。

手順3：必須の値を確認する

  • 新規商品のインポートで必須の列は Title のみです。各商品の行に Title を入れます。
  • URL handle は空でもかまいません（Title から自動で作られます）。ただしスペースは含められません。
  • Status 列を置く場合は値が必要です（active／draft／archived）。列がない場合は自動で active になります。下書きとして登録するなら draft。
  • Fulfillment service 列を置く場合、空欄はエラーになる旨が公式にあります。使わない場合は manual。
  • Inventory tracker を設定する（在庫を追跡する）場合は、Inventory quantity に数値が必要です。
  • Packed product length／width／height／dimension unit の4列は、すべて埋めるかすべて空欄にします（その行の Requires shipping が false の場合を除く）。
  • Price は、説明表では既定値 0.00 とされる一方、公式のエラー一覧には「price can't be blank」もあり、どの条件でエラーになるかは公式で確認できていません。価格は入れておくのが無難です。

手順4：値の形式を確認する

  • 金額（Price、Compare-at price、Cost per item）は通貨記号なしの数値（例 9.99）。
  • true／false の列（Published on online store、Charge tax、Requires shipping、Gift card）は true または false。
  • Continue selling when out of stock は deny または continue。
  • Weight value (grams) はグラム単位の数値のみ（単位・小数点なし。例 5.125 kg → 5125）。
  • Weight unit for display は g／kg／lb／oz、Packed product dimension unit は cm／in。
  • Tags は1商品あたり最大250個。Collection は最大255文字、Image alt text は最大512文字、SEO title は最大70文字、SEO description は最大320文字。
  • Product image URL は https:// で始まる公開アクセス可能な URL で、ファイル名に _thumb／_small／_medium を含めない。
  • ギフトカードは CSV インポートでは作成できず、管理画面でのみ作成できる旨が公式にあります。
  • 有効値は公式の説明表では小文字で書かれていますが、公式サンプルCSVには TRUE や Active などの大文字表記も含まれます。大文字・小文字の受理範囲は公式では確認できていません。

手順5：事前チェッカーで確認する

手順1〜4の多くは、事前チェッカーにファイルを入れると一度に確認できます。ファイルはブラウザ内だけで処理し、送信しません。

  1. チェッカーを開き、商品CSVを選びます。
  2. 「仕様不適合」が出たら、表示された物理行・列名・原因・期待形式に沿って直します。
  3. 「注意」は、公式では確認できていない点や想定用途とのずれです。内容を読んで判断してください。
  4. 「対象外・未検査」は、チェッカーが確認していない事項です。合格を意味しません。

チェッカーが確認しないこと

  • バリエーション（同じハンドルの複数行、Option2／Option3 の使用など）を含む行の値
  • Product category や Google Product Category がタクソノミーに一致するか
  • ストアにすでにある商品のハンドルとの重複、カスタムのフルフィルメントサービスがストアに登録済みか、画像URLに実際にアクセスできるか
  • 15 MB 以外の上限（行数上限等は未検査）、商品の更新（上書き）用途の条件

チェッカーの結果は仕様ベースの事前チェックであり、実際のインポート結果はご自身のストアで確認してください。
